# helpers

Small functions for rendering pages, exported from `tenoncms` and `tenoncms/client`.

| File             | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `slugify.ts`     | `slugify()` and `SLUG_PATTERN`. The admin uses the same file.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `seo-meta.ts`    | `seoHead(doc, settings?)`: the `<head>` tags (`title`, `meta`, `links`) of `seoMeta()`, used by `useTenonSeo()` and the `Seo` components. `seoMeta(doc, settings?)`: the `<head>` values (title, description, noindex, canonical, alternates, image, verification). Title and description are templates (`{field}`, `{site.title}`): the page's, else the collection's `templates`, else the `seo` global's, else `DEFAULT_SEO_TITLE`, filled at render time. The admin's SEO editor runs it too. `alternates` (`{ hreflang, href }[]`) comes from `doc.alternates`; `canonical` is the document's own locale's URL there, else `general.url` plus `permalink` (a read with `permalink: true`), else `path`. |
| `menu-items.ts`  | `menuItems(items)`: render-ready entries of a populated menu read (`label` falls back to the link's title, a heading has `href: null`, broken links are left out with their children). Other item fields pass through with their types.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `sitemap-xml.ts` | `sitemapXml(entries)` and `SitemapEntry`: a `sitemap.xml` with `xhtml:link` alternates. Writes URLs as given.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `robots-txt.ts`  | `robotsTxt({ rules, sitemaps })` and `RobotsRule`: a `robots.txt`. A group without paths gets an empty `Disallow:`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `breadcrumbs.ts` | `breadcrumbs()`: walks the populated `parent` chain. No queries.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `locale-path.ts` | `localeFromPath()`, `localizePath()` and `switchTarget()`: locale prefixes of URL paths and the target of a language switch. They take the `localization` config (`cms.localization`, or `client.localization()` in the browser) and read `locales`, `defaultLocale` and `routing`.                                                                                                                                                                                                                                                                                                                                                                                                                          |

`switchTarget()` uses a document's published alternate when available, otherwise the target locale's homepage. Homepage fallbacks belong only in navigation; `seoMeta()` emits the published alternates as `hreflang` links.

Helpers MUST have no imports, so they run in the browser.
