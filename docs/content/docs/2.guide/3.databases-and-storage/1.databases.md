## Pick a database

- One row per database: the config entry, the package to install, where it fits.
- UI: table.

## SQLite and Turso

- `libsql()`: a local file in development, Turso by URL in production. `sqlite()` needs no package.

## Postgres and PGlite

- `postgres()` with a URL or pool options. `pglite()` for local development and tests.

## Migrations

- Tenon creates and updates its tables on the first start. No command to run.
