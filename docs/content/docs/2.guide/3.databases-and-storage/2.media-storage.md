## Pick a storage

- Local disk, S3-compatible bucket, R2. Which one fits which deploy target.
- UI: table.

## Local disk

- `local({ dir })`. The folder needs a persistent disk.

## S3 and R2

- `s3()` and `r2()` with their options. The browser uploads straight to the bucket, so it needs CORS.
- `publicUrl` serves files from the bucket. Without it, Tenon serves them.
