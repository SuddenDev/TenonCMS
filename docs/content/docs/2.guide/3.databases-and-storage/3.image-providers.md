## Do you need one?

- Without a provider, images are served as uploaded.

## Providers

- Rendering providers make the variants. URL providers build URLs for an image service.
- One short section each: `ipx`, `cloudflare`, `vercel`, `netlify`, `imgix`, `cloudinary`, `imagekit`, `bunny`, `imgproxy`, `thumbor`.
- UI: overview table, then `tabs` per provider.

## Sizes and presets

- `images.sizes`, `format`, `quality`, `presets`.
- [`tenon media regenerate`](/docs/cli/media) after a change.
