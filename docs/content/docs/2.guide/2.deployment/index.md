## What a deployment needs

- A server runtime, a database that persists, a place for media files, the secret and the public URL.

## Pick a target

- Target by framework, database, media storage and image provider.
- UI: table; `card-group` with Node, Vercel, Cloudflare.

## Before going live

- Secret and site URL set, data on persistent storage, email set up, a backup plan.
- UI: checklist.
