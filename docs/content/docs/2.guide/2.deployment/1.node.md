## Build and start

- The commands per framework.
- UI: `code-group` synced by framework.

## Persistent data

- The database file and the upload folder live on a persistent disk. Or: a database server and a bucket.

## Environment

- `TENON_SECRET`, `DATABASE_URL`, `TENON_SITE_URL`. HTTPS behind a reverse proxy.
- Native packages match the OS and CPU of the server.
