## Route the API

- `/_tenon/*`, `/sitemap.xml` and `/robots.txt` go to `cms.fetch(request)`.

## Serve the admin

- With Vite: `tenonAdmin()` and `#tenon/admin-html`.
- Without Vite: a page with an empty element and `mountAdmin()`.
- Without Vite, custom admin code from `clientRef()` needs its registry passed to `mountAdmin()` by hand.
- `admin: false` ships no admin.
