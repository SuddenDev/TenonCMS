---

## Create a project

- `npm create tenoncms@latest` with Astro picked.

## Add to an existing project

- Install `tenoncms`, a database driver and an SSR adapter.
- Add `tenonCms()` to `astro.config.ts` and the secrets to the `astro:env` schema.
- Create `tenon.config.ts`, start the dev server, create the admin account.
- UI: `steps`; `code-group` for the files.

## Read content

- `Astro.locals.tenon` is the typed instance, bound to the request.
- Pages with `prerender = false` read live content. Prerendered pages read at build time.

## Render and preview

- The components of `tenoncms/astro/components`.
- The integration adds the live preview to every page.
- `Astro.locals.locale` and `Astro.locals.path` for localized routes.

## Integration options

- `entry`, `preview`, `sitemap`, `robots`, `jobs`.
- UI: `field-group`.

## Deploy

- UI: `card-group` with Node, Vercel, Cloudflare.
