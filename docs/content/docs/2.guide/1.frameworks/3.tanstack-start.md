## Create a project

- `npm create tenoncms@latest` with TanStack Start picked.

## Add to an existing project

- Install `tenoncms` and a database driver. Add `tenonAdmin()` to `vite.config.ts`.
- Add the server routes: the API, the admin page, `sitemap.xml`, `robots.txt`.
- Register the types in `tsconfig.json`, create `tenon.config.ts`, create the admin account.
- UI: `steps`; `code-tree` for the route files.

## Read content

- Server functions call the instance. Loaders call the server functions.

## Render and preview

- The components of `tenoncms/react`.
- `preview()` once in the root component, `useDraft()` around loader data.

## Deploy

- UI: `card-group` with Node, Vercel.
