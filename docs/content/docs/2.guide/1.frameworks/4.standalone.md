---
title: Standalone
description: Run Tenon headless, with the API and the admin and no site.
---

## When to use it

- A frontend that is not a Vite app, or several frontends.

## Create a project

- `npm create tenoncms@latest` with Standalone picked.
- The three files: `server.ts`, `vite.config.ts`, `tenon.config.ts`.
- UI: `code-tree`.

## Read content from another app

- `createClient({ baseUrl })`. Public reads need no key, the rest uses an API key.
- `site.url` is the public site. `auth.baseURL` is the CMS origin.

## Deploy

- UI: `card-group` with Node, Vercel.
