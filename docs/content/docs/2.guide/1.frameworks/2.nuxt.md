title: Nuxt
description: Set up Tenon in a Nuxt project.
---

## Create a project

- `npm create tenoncms@latest` with Nuxt picked.

## Add to an existing project

- Install `tenoncms` and a database driver.
- Add `tenoncms/nuxt` to `modules` and the keys to `runtimeConfig`.
- Create `tenon.config.ts`, set the `NUXT_` variables, create the admin account.
- UI: `steps`; `code-group` for the files.

## Read content

- `useTenon()`: `find`, `findOne`, `findById`, `getGlobal`, each returns a `useAsyncData` result.
- Getters for options that depend on the route.
- Server routes import the instance from `#tenon/config`.

## Render and preview

- The auto-imported `Tenon*` components and `useTenonSeo()`.
- The module starts the live preview. `useLivePreview()` and `useBlockEdit()`.
- `useLocale()` and `useAlternates()` for localized routes.

## Module options

- `tenonCms: { entry, sitemap, robots, jobs }`.
- UI: `field-group`.

## Deploy

- UI: `card-group` with Node, Vercel.
