## A first plugin

- `definePlugin()` with a name, one collection and one route.

## What a plugin can define

- `collections`, `globals`, `hooks`, `routes`, `jobs`, `richtext`, `admin`, lifecycle hooks.
- UI: `field-group`.

## Publish it

- The package layout with a server and a browser entry. `tenoncms` as a peer dependency.
- UI: `code-tree`.
