- One heading per symptom, as a reader types it into the search. Each: cause, then fix.

## Setup

- Sign-up answers 403: the database already has a user.
- TanStack Start: `/_tenon` answers 404 because of the route file name.

## Build and deploy

- `nuxt preview` and `astro preview`: relative paths and `.env`.
- The libSQL binary does not match the server's platform.
- Uploads fail on serverless: no writable disk, or bucket CORS.

## Auth and jobs

- Sign-in links point to the wrong origin: `site.url` and `auth.baseURL`.
- Scheduled publishing does nothing: no clock on this host.
