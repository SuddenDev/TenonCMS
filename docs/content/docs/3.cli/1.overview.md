## Two commands

- `npm create tenoncms` starts a project. `tenon` comes with `tenoncms` and maintains it.

## Local or remote

- Without `--url`, the CLI loads `tenon.config.ts` and opens the database itself.
- With `--url`, it talks to a running site after `tenon login`.

## CI

- `TENON_URL` and `TENON_API_KEY` in place of the flags and the login.
