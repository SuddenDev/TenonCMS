---
title: tenon backup
description: Back up a project and restore it.
---

## `tenon backup`

- What the backup holds, and the flags: `--dry-run`, `--out`, `--content-only`, `--no-media`.

## `tenon restore`

- The check before a restore, and the flags: `--dry-run`, `--yes`, `--backup`.
- A restore replaces all data.
- UI: `field-group` for flags; `caution` callout.
