---
title: Package exports
description: Every import path of the tenoncms package, and what it provides.
---

`tenoncms` is one package with many import paths. Each path loads only what it needs, so a page that reads content does not load the admin, a database driver or an image library.

## Core

| Import              | Provides                                                                                                                                                                                                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tenoncms`          | `defineCms`, `defineCollection`, `defineGlobal`, `definePlugin`, `defineTask`, `verifyWebhook`, the [error classes](/docs/core/reference/errors-and-types), SEO helpers like `seoHead` and `sitemapXml`, path helpers like `localizePath`, `slugify` and every config type |
| `tenoncms/client`   | `createClient`, `createRequestClient`, `CmsError` and the [content types](/docs/core/reference/errors-and-types#content-types). See [Client](/docs/core/reference/api/client)                                                                                              |
| `tenoncms/register` | Types only. Registers your `cms` for the client. See [Types without an adapter](/docs/core/working-with-content/http-api-and-client#types-without-an-adapter)                                                                                                              |
| `tenoncms/auth`     | `magicLink()` and `emailOTP()`, the better-auth plugins with sign-up off. See [Authentication](/docs/core/users-and-access/authentication)                                                                                                                                 |
| `tenoncms/presets`  | `pagesPreset`, `menuPreset`, `stringsPreset`, and the parts `page`, `seo`, `menu`, `strings`, `settings`. See [Presets](/docs/core/content-modeling/presets)                                                                                                               |

## Databases

| Import                | Provides                                                              |
| --------------------- | --------------------------------------------------------------------- |
| `tenoncms/sqlite`     | `sqlite(path)`, a SQLite file through `node:sqlite`                   |
| `tenoncms/libsql`     | `libsql(url)`, for libSQL and Turso                                   |
| `tenoncms/postgres`   | `postgres(url)`, for Postgres                                         |
| `tenoncms/pglite`     | `pglite(client)`, for PGlite                                          |
| `tenoncms/cloudflare` | `durableObject()` and `tenonObject()`, for SQLite in a Durable Object |

See [Databases](/docs/guide/databases-and-storage/databases).

## Frameworks

| Import           | Provides                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `tenoncms/astro` | The Astro integration `tenonCms()`. See [Astro](/docs/guide/frameworks/astro)                                                        |
| `tenoncms/nuxt`  | The Nuxt module, set with `tenonCms` in `nuxt.config.ts`. See [Nuxt](/docs/guide/frameworks/nuxt)                                    |
| `tenoncms/vite`  | `tenonAdmin()`, the Vite plugin for TanStack Start and other frameworks. See [TanStack Start](/docs/guide/frameworks/tanstack-start) |

| Import                      | Provides                                                                     |
| --------------------------- | ---------------------------------------------------------------------------- |

| `tenoncms/vue`              | `Blocks`, `Image`, `Link`, `Picture`, `Richtext` and `useBlockEdit` for Vue  |
| `tenoncms/react`            | `Blocks`, `Image`, `Link`, `Picture`, `Richtext` and `Seo` for React         |
| `tenoncms/components`       | `linkAttrs`, `imageAttrs`, `pictureAttrs` and `editBlock`, for any framework |

See [Components](/docs/core/building-your-site/components).

## Admin

| Import                 | Provides                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------ |
| `tenoncms/admin`       | `clientRef`, `translate`, `translator` and the types of custom fields, pages and bar items |
| `tenoncms/admin/vue`   | `renderVue`, to mount a Vue component in the admin                                         |
| `tenoncms/admin/react` | `renderReact`, to mount a React component in the admin                                     |
| `tenoncms/admin/mount` | `mountAdmin()`, to mount the whole admin in a page of your own                             |
| `tenoncms/admin/bar`   | `mountAdminBar()`, which mounts the admin bar on a page                                    |

See [Custom fields](/docs/core/customization/custom-fields) and [Custom pages and actions](/docs/core/customization/custom-pages-and-actions).

## Media storage

| Import                   | Provides                                                                 |
| ------------------------ | ------------------------------------------------------------------------ |
| `tenoncms/media/local`   | `local({ dir })`, files on disk. Not on Cloudflare Workers               |
| `tenoncms/media/s3`      | `s3()`, any S3-compatible storage                                        |
| `tenoncms/media/r2`      | `r2()`, Cloudflare R2, with a binding or with the S3 API                 |
| `tenoncms/media/default` | The default storage in `.uploads`. Tenon uses it when `media` is not set |

See [Media storage](/docs/guide/databases-and-storage/media-storage).

| `tenoncms/media/netlify`    | `netlify()`, Netlify Image CDN                           |
| `tenoncms/media/imgix`      | `imgix({ baseURL })`                                     |
| `tenoncms/media/cloudinary` | `cloudinary({ baseURL })`                                |
| `tenoncms/media/imagekit`   | `imagekit({ baseURL })`                                  |
| `tenoncms/media/bunny`      | `bunny({ baseURL })`                                     |
| `tenoncms/media/imgproxy`   | `imgproxy({ baseURL, key, salt })`                       |
| `tenoncms/media/thumbor`    | `thumbor({ baseURL, key, origin })`                      |

See [Image providers](/docs/guide/databases-and-storage/image-providers).

## Email

| Import                      | Provides                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| `tenoncms/email/smtp`       | `smtp()`. Needs the `nodemailer` package. See [SMTP](/docs/core/operations/email/smtp)      |
| `tenoncms/email/cloudflare` | `cloudflareEmail()`. See [Cloudflare Email Service](/docs/core/operations/email/cloudflare) |

## Plugins

| Import                       | Provides                                                 |
| ---------------------------- | -------------------------------------------------------- |
| `tenoncms/plugins/redirects` | `RedirectsPlugin()` and `resolveRedirect()`              |
| `tenoncms/plugins/example`   | `ExamplePlugin()`, code to copy for a plugin of your own |

The paths below them, like `tenoncms/plugins/redirects/admin`, hold the admin parts of these plugins. The plugins load them through `clientRef()`. See [Plugins](/docs/core/customization/plugins).
