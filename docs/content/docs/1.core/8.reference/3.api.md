## Read methods

- `find`, `findOne`, `findById`, `getGlobal`.

## Write methods

- `create`, `update`, `delete`, `setGlobal`, `publish`, `unpublish`, `discard`.

## Query options

- `where`, `limit`, `select`, `populate`, `locale`, `permalink`, `alternates`.
- UI: `field-group`.

## HTTP routes

- Method, path and what it does, per area. Status codes and the error body.
- UI: tables.

## Errors and type helpers

- `ValidationError`, `ConflictError`, `ForbiddenError`, `CmsError`.
- `DocumentOf`, `GlobalOf`, `BlockOf`, `Collections`, `Globals`.
