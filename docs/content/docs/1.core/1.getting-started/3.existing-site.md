---
title: Add to an Existing Site
description: Add Tenon to an Astro, Nuxt or TanStack Start app you already have.
---

If you already have an existing app, you can add Tenon to it. For specific examples and details to adding a database, storage, email and more, please look at the specific sections inside the docs. For demonstrative purposes and to keep it simple, this tutorial uses `SQLite` as the database and `node` as the target deployment.

To start from scratch instead, see the [Quick Start](/docs/core/getting-started/quick-start).

::steps{level="2"}

## Install the packages

Install Tenon and the SQLite driver (or use the built in `node:sqlite` and skip `libsql`):

:::code-group{sync="pm"}

```bash [npm]
npm install tenoncms @libsql/client
```

```bash [pnpm]
pnpm add tenoncms @libsql/client
```

```bash [yarn]
yarn add tenoncms @libsql/client
```

```bash [bun]
bun add tenoncms @libsql/client
```

:::

Tenon runs on the server, so your app needs a server build. Nuxt needs nothing else. Astro and TanStack Start need one more package:

:::tabs{sync="framework"}

::::tabs-item{label="Astro"}

:::::code-group{sync="pm"}

```bash [npm]
npm install @astrojs/node
```

```bash [pnpm]

```

```bash [yarn]
yarn add @astrojs/node
```

```bash [bun]
bun add @astrojs/node
```

## Add a collection

A collection is a list of documents with the same fields. Create a file for a `posts` collection:

```ts [cms/collections/posts.ts]
import { defineCollection } from "tenoncms";

export const posts = defineCollection({
  titleField: "title",
  fields: {
    title: { type: "text", required: true },
    slug: { type: "slug", from: "title", required: true, unique: true },
    body: { type: "textarea" },
  },
});
```

See [Fields](/docs/core/reference/field-types) for information on field types and options.

## Create the CMS instance

Create `tenon.config.ts` at the project root. It reads the secret and the database URL from environment variables. Each framework reads them in its own way:

:::code-group{sync="framework"}

```ts [Astro]
import { DATABASE_URL, TENON_SECRET, TENON_SITE_URL } from "astro:env/server";
import { defineCms } from "tenoncms";
import { libsql } from "tenoncms/libsql";
import { posts } from "./collections/posts";

export default defineCms({
  collections: { posts },
  database: libsql(DATABASE_URL),
  secret: TENON_SECRET,
  site: { url: TENON_SITE_URL, name: "My Site" },
});
```

```ts [Nuxt]
import { defineCms } from "tenoncms";
import { libsql } from "tenoncms/libsql";
import { posts } from "./collections/posts";

const config = useRuntimeConfig();

export default defineCms({
  collections: { posts },
  database: libsql(config.databaseUrl),
  secret: config.tenonSecret,
  site: { url: config.tenonSiteUrl || undefined, name: "My Site" },
});
```

```ts [TanStack Start]
import { defineCms } from "tenoncms";
import { libsql } from "tenoncms/libsql";
import { posts } from "./collections/posts";

export default defineCms({
  collections: { posts },
  database: libsql(process.env.DATABASE_URL ?? "file:./cms.db"),
  secret: process.env.TENON_SECRET!,
  site: { url: process.env.TENON_SITE_URL, name: "My Site" },
});
```

:::

For what each option does, see [Configuration](/docs/core/getting-started/configuration).

## Connect the framework

The framework setup adds the API at `/_tenon`, the admin at `/admin`, and gives your pages the CMS instance:

:::tabs{sync="framework"}

::::tabs-item{label="Astro"}

Add the integration, and declare the variables in the `env` schema:

```ts [astro.config.ts]
import node from "@astrojs/node";
import { defineConfig, envField } from "astro/config";
import tenonCms from "tenoncms/astro";

export default defineConfig({
  adapter: node({ mode: "standalone" }),
  integrations: [tenonCms()],
  env: {
    schema: {
      TENON_SECRET: envField.string({ context: "server", access: "secret", min: 32 }),
      DATABASE_URL: envField.string({
        context: "server",
        access: "secret",
        default: "file:./cms.db",
      }),
      TENON_SITE_URL: envField.string({
        context: "server",
        access: "secret",
        url: true,
        optional: true,
      }),
    },
  },
});
```

The integration finds `tenon.config.ts` at the project root.

::::

::::tabs-item{label="Nuxt"}

Add the module, and declare the values in `runtimeConfig`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["tenoncms/nuxt"],
  runtimeConfig: {
    tenonSecret: "",
    databaseUrl: "file:./cms.db",
    tenonSiteUrl: "",
  },
});
```

The module finds `tenon.config.ts` at the project root.

::::

::::tabs-item{label="TanStack Start"}

Add `tenonAdmin()` to the Vite config. It builds the admin. Then add route files that send requests to the CMS and serve the admin page. The sitemap and `robots.txt` routes are optional.

:::::code-tree{defaultValue="vite.config.ts"}

```ts [vite.config.ts]
import { tanstackStart } from "@tanstack/react-start/plugin/vite";
import viteReact from "@vitejs/plugin-react";
import { nitro } from "nitro/vite";
import { tenonAdmin } from "tenoncms/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [tanstackStart(), nitro(), viteReact(), tenonAdmin()],
});
```

```ts [src/routes/[_]tenon.$.ts]
import { createFileRoute } from "@tanstack/react-router";
import cms from "../../tenon.config";

const handle = ({ request }: { request: Request }) => cms.fetch(request);

export const Route = createFileRoute("/_tenon/$")({
  server: { handlers: { GET: handle, POST: handle, PUT: handle, DELETE: handle } },
});
```

```ts [src/routes/admin.$.ts]
import { createFileRoute } from "@tanstack/react-router";
import html from "#tenon/admin-html";

export const Route = createFileRoute("/admin/$")({
  server: {
    handlers: {
      GET: () => new Response(html, { headers: { "content-type": "text/html; charset=utf-8" } }),
    },
  },
});
```

```ts [src/routes/sitemap[.]xml.ts]
import { createFileRoute } from "@tanstack/react-router";
import cms from "../../tenon.config";

export const Route = createFileRoute("/sitemap.xml")({
  server: { handlers: { GET: ({ request }) => cms.fetch(request) } },
});
```

```ts [src/routes/robots[.]txt.ts]
import { createFileRoute } from "@tanstack/react-router";
import cms from "../../tenon.config";

export const Route = createFileRoute("/robots.txt")({
  server: { handlers: { GET: ({ request }) => cms.fetch(request) } },
});
```

:::::

The brackets in the file names escape characters that TanStack Router treats as syntax. A plain `_tenon` file would be a layout route.

::::

## Set the secret

Tenon signs sessions with a secret of at least 32 characters. Generate one:

```bash
openssl rand -hex 32
```

Put it in `.env` at the project root:

:::tabs{sync="framework"}

::::tabs-item{label="Astro"}

```bash [.env]
TENON_SECRET=<your secret>
```

::::

::::tabs-item{label="Nuxt"}

```bash [.env]
NUXT_TENON_SECRET=<your secret>
```

::::

::::tabs-item{label="TanStack Start"}

```bash [.env]
TENON_SECRET=<your secret>
```

::::

:::

Keep the secret, the database and the uploads out of git:

```bash [.gitignore]
.env
cms.db*
.uploads
```

## Create the admin account

Start the dev server, open the URL it prints and add `/admin`. Enter your name, email and a password, then select **Create admin account**.

The first account is the admin. Create a post, then select **Publish**. Every save is a draft until you publish it.

## Show the posts on a page

Read the posts on a page. The page runs on the server and calls Tenon directly, without HTTP:

:::code-group{sync="framework"}

```astro [src/pages/blog.astro]
---
export const prerender = false;

const posts = await Astro.locals.tenon.find("posts");
---

<h1>Posts</h1>
<ul>
  {posts.map((post) => <li>{post.title}</li>)}
</ul>
```

```vue [app/pages/blog.vue]
<script setup lang="ts">
const { data: posts } = await useTenon().find("posts");
</script>

<template>
  <main>
    <h1>Posts</h1>
    <ul>
      <li v-for="post in posts" :key="post.id">{{ post.title }}</li>
    </ul>
  </main>
</template>
```

```tsx [src/routes/blog.tsx]
import { createFileRoute } from "@tanstack/react-router";
import { createServerFn } from "@tanstack/react-start";
import cms from "../../tenon.config";

const getPosts = createServerFn().handler(() => cms.find("posts"));

export const Route = createFileRoute("/blog")({
  loader: () => getPosts(),
  component: Blog,
});

function Blog() {
  const posts = Route.useLoaderData();
  return (
    <main>
      <h1>Posts</h1>
      <ul>
        {posts.map((post) => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </main>
  );
}
```

:::

Open `/blog`. It lists the post you published. `post.title` is typed from the collection, so your editor completes it and flags a typo.

In Astro, `prerender = false` makes the page read the content on each request. A prerendered page reads it once, at build time.
