---
title: Size
description: A number with a CSS unit, for spacing and widths that editors set.
---

:field-preview{name="size"}

## Example

```ts [cms/blocks/section.ts]
fields: {
  gap: { type: "size", units: ["px", "rem"], min: 0 },
  maxWidth: { type: "size", units: ["px", "%", "ch"], default: { value: 720, unit: "px" } },
}
```

The first unit in `units` is preselected. A read returns the number and the unit:

```ts
section.gap; // { value: 2, unit: "px" | "rem" } | null | undefined
```

### Render it

Join the two parts to get a CSS value:

::code-group{sync="framework"}

```astro [Astro]
<section style={{ gap: section.gap && `${section.gap.value}${section.gap.unit}` }}>
  <slot />
</section>
```

```vue [Nuxt]
<template>
  <section :style="{ gap: section.gap && `${section.gap.value}${section.gap.unit}` }">
    <slot />
  </section>
</template>
```

```tsx [TanStack Start]
<section style={{ gap: section.gap ? `${section.gap.value}${section.gap.unit}` : undefined }}>
  {children}
</section>
```

::

## Options

::field-group
:::field{name="type" type='"size"' required}
:::

:::field{name="units" type="string[]" required}
The CSS units the editor can pick, like `["px", "rem", "vh"]`. The first is preselected.
:::

:::field{name="min" type="number"}
The smallest number.
:::

:::field{name="max" type="number"}
The largest number.
:::

:::field{name="step" type="number"}
The number MUST be `min` (or `0`) plus a whole number of steps.
:::

:::field{name="placeholder" type="string"}
Shown in the empty input.
:::
