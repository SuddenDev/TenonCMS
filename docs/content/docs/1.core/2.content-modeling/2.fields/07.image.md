An `image` field holds an image from the [media library](/docs/core/content-modeling/media). For PDFs and other files, use a [`file` field](/docs/core/content-modeling/fields/file).

:field-preview{name="image"}

## Example

```ts [cms/collections/posts.ts]
export const posts = defineCollection({
  fields: {
    hero: { type: "image", required: true },
    gallery: { type: "image", many: true },
    avatar: { type: "image", maxSize: 2 * 1024 ** 2, folder: "avatars" },
  },
});
```

A read loads the image, like a [relation](/docs/core/content-modeling/fields/relation):

```ts
{
  id: "m1",
  url: "/_tenon/media/files/blog/hero.jpg",
  src: "/_tenon/media/img/w_1920&f_webp&q_85/blog/hero.jpg",
  srcset: "/_tenon/media/img/w_320&f_webp&q_85/blog/hero.jpg 320w, …",
  width: 2400,
  height: 1600,
  alt: "Harbour at dusk",
  mimeType: "image/jpeg",
  size: 482133,
  folder: "blog",
  filename: "hero.jpg",
  key: "blog/hero.jpg",
}
```

- `url` is the original. `src` and `srcset` are the resized copies.
- With `populate: false`, the field holds the id.

### Render it

The `Image` component writes `src`, `srcset`, `width`, `height` and `alt`:

::code-group{sync="framework"}

```astro [Astro]
---
import { Image } from "tenoncms/astro/components";
---

<Image image={post.hero} sizes="(min-width: 720px) 720px, 100vw" />

{post.gallery?.map((image) => <Image image={image} sizes="33vw" />)}
```

```vue [Nuxt]
<template>
  <TenonImage :image="post.hero" sizes="(min-width: 720px) 720px, 100vw" />

  <TenonImage v-for="image in post.gallery" :key="image.id" :image="image" sizes="33vw" />
</template>
```

```tsx [TanStack Start]
import { Image } from "tenoncms/react";

<>
  <Image image={post.hero} sizes="(min-width: 720px) 720px, 100vw" />
  {post.gallery?.map((image) => (
    <Image key={image.id} image={image} sizes="33vw" />
  ))}
</>;
```

::

`sizes` tells the browser how wide the image shows, so it picks the right copy from `srcset`. See [Components](/docs/core/building-your-site/components) for `Picture`.

## With or without an image provider

An [image provider](/docs/guide/databases-and-storage/image-providers) makes the resized copies. You do not have to use one.

| Setup           | `src`               | `srcset`      | Use it when                                                 |
| --------------- | ------------------- | ------------- | ----------------------------------------------------------- |
| No provider     | The original        | Empty         | The images are small, or the framework resizes them for you |
| With a provider | A resized WebP copy | One per width | You want responsive images without another tool             |

- Without a provider, the `Image` component still renders `width`, `height` and `alt`. The browser loads the original.
- With a provider, set `media.images` in the [media config](/docs/core/content-modeling/media#responsive-images). Tenon supports `ipx`, `cloudflare`, `vercel`, `netlify`, `imgix` and more.
- To pick one, see [Do you need one?](/docs/guide/databases-and-storage/image-providers#do-you-need-one) and [Providers](/docs/guide/databases-and-storage/image-providers#providers).

## Image sizes

With an image provider, `image` sets how a read builds `src` and `srcset`. Use a named preset, or set the options on the field:

```ts
avatar: { type: "image", image: { preset: "avatar" } },
cover: { type: "image", image: { sizes: [800, 1600], quality: 70 } },
banner: { type: "image", image: { width: 1600, height: 600, fit: "cover" } },
```

The field's own options override the preset's. Sizes and presets are set with the provider. See [Sizes and presets](/docs/guide/databases-and-storage/image-providers#sizes-and-presets).

## Use your framework's image component

Instead of a provider, you can let the framework resize the image. Leave `media.images` off and pass `url`, `width`, `height` and `alt` to the framework's own component.

`url` is a path on your site. The framework's optimizer MUST get the full URL, and it MUST allow your site's host.

::code-group{sync="framework"}

```astro [Astro]
---
import { Image } from "astro:assets";

const hero = post.hero;
const src = new URL(hero.url, Astro.site).href;
---

<Image src={src} width={hero.width} height={hero.height} alt={hero.alt ?? ""} />
```

```vue [Nuxt]
<script setup lang="ts">
const { origin } = useRequestURL();
</script>

<template>
  <NuxtImg
    :src="`${origin}${post.hero.url}`"
    :width="post.hero.width"
    :height="post.hero.height"
    :alt="post.hero.alt ?? ''"
    sizes="(min-width: 720px) 720px, 100vw"
  />
</template>
```

```tsx [TanStack Start]
// TanStack Start has no built-in image component. Use the `Image` from `tenoncms/react` with a provider, or an image library of your choice.
```

::

Allow the host in the framework config:

::code-group{sync="framework"}

```ts [astro.config.ts]
export default defineConfig({
  site: "https://example.com",
  image: { domains: ["example.com"] },
});
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["@nuxt/image"],
  image: { domains: ["example.com"] },
});
```

```ts [TanStack Start]
// No setup. TanStack Start has no image component.
```

::

- Astro needs `site` set, so it can build the full URL. Without `width` and `height`, add `inferSize`.
- Nuxt needs the [`@nuxt/image`](https://image.nuxt.com) module.
- The field preset and `image` options do not apply, because Tenon makes no copies.

## Deleting an image

An image that a field uses cannot be deleted. The delete fails with a `409` and lists the documents that use it. Set `onDelete: "set-null"` to clear the field instead.

## Options

::field-group
:::field{name="type" type='"image"' required}
:::

:::field{name="many" type="boolean"}
Store a list of images instead of one. With `required`, at least one. Default `false`.
:::

:::field{name="accept" type="string[]"}
The allowed image types, like `["image/png", "image/webp"]`. Default: all images.
:::

:::field{name="maxSize" type="number"}
The largest file in bytes. It narrows `media.maxSize`.
:::

:::field{name="folder" type="string" :badges='[{"label":"Admin only","color":"note"}]'}
The folder that **Upload new** in the field puts the image in, like `"avatars"`. Default: the root.
:::

:::field{name="onDelete" type='"restrict" | "set-null"'}
What happens when the image is deleted. Default `"restrict"`. A `required` field cannot use `"set-null"`.
:::

:::field{name="image" type="{ preset, sizes, width, height, fit, format, quality, background, blur }"}
How reads build `src` and `srcset`. Needs `media.images`. See [Image sizes](#image-sizes).
:::
::
