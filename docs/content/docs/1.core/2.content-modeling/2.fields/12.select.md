---
title: Select
description: One or more values from a fixed list of options.
---

:field-preview{name="select"}

## Example

```ts [cms/collections/posts.ts]
export const posts = defineCollection({
  fields: {
    category: { type: "select", options: ["news", "guide"], required: true },
    tags: { type: "select", options: ["vue", "react", "astro"], many: true },
    color: {
      type: "select",
      options: [
        { value: "brand", label: "Brand color" },
        { value: "muted", label: "Muted" },
      ],
    },
  },
});
```

The type of a read is the union of the values:

```ts
post.category; // "news" | "guide"
post.tags; // ("vue" | "react" | "astro")[] | null | undefined
post.color; // "brand" | "muted" | null | undefined
```

- An option is a string, or `{ value, label }` when the label in the admin should differ from the stored value.
- A label can be translated: `{ value: "brand", label: { en: "Brand color", de: "Markenfarbe" } }`.

### Render it

::code-group{sync="framework"}

```astro [Astro]
---
const categories = { news: "News", guide: "Guide" };
---

<article class={`category-${post.category}`}>
  <span>{categories[post.category]}</span>
  <ul>
    {post.tags?.map((tag) => <li>#{tag}</li>)}
  </ul>
</article>
```

```vue [Nuxt]
<script setup lang="ts">
const categories = { news: "News", guide: "Guide" };
</script>

<template>
  <article :class="`category-${post.category}`">
    <span>{{ categories[post.category] }}</span>
    <ul>
      <li v-for="tag in post.tags" :key="tag">#{{ tag }}</li>
    </ul>
  </article>
</template>
```

```tsx [TanStack Start]
const categories = { news: "News", guide: "Guide" };

<article className={`category-${post.category}`}>
  <span>{categories[post.category]}</span>
  <ul>
    {post.tags?.map((tag) => (
      <li key={tag}>#{tag}</li>
    ))}
  </ul>
</article>;
```

::

A read returns the stored value, not the label. Map it to a label in your site, as above. Because the type is a union, TypeScript checks that the map covers every value.

## Many values

`many: true` stores a list of distinct values. With `required`, the list needs at least one value:

:field-preview{name="select-many"}

A `many` select cannot be filtered and cannot be `unique`.

## Appearance

`appearance` picks the input in the admin:

| Appearance             | Input                                      | Fits                      |
| ---------------------- | ------------------------------------------ | ------------------------- |
| `"dropdown"` (default) | A menu. With `many`, a combobox with chips | Many options              |
| `"list"`               | Radio buttons, or checkboxes with `many`   | A few options             |
| `"buttons"`            | A row of toggle buttons                    | Two to five short options |

```ts
align: { type: "select", options: ["left", "center", "right"], appearance: "buttons" },
```

## Options

:::field{name="options" type="(string | { value, label })[]" required}

:::

:::field{name="many" type="boolean"}
Store a list of values instead of one. Default `false`.
