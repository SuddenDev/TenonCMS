## Example

```ts [cms/collections/events.ts]
export const events = defineCollection({
  fields: {
    title: { type: "text", required: true },
    day: { type: "date", required: true },
    startsAt: { type: "datetime" },
  },
});
```

Both read as ISO strings:

```ts
event.day; // "2026-10-17"
event.startsAt; // "2026-10-17T12:00:00.000Z"
```

### Render it

::code-group{sync="framework"}

```astro [Astro]
<time datetime={event.day}>
  {new Date(event.day).toLocaleDateString("en", { dateStyle: "long", timeZone: "UTC" })}
</time>
```

```vue [Nuxt]
<template>
  <time :datetime="event.day">
    {{ new Date(event.day).toLocaleDateString("en", { dateStyle: "long", timeZone: "UTC" }) }}
  </time>
</template>
```

```tsx [TanStack Start]
<time dateTime={event.day}>
  {new Date(event.day).toLocaleDateString("en", { dateStyle: "long", timeZone: "UTC" })}
</time>
```

::

- A `date` has no time zone. Format it with `timeZone: "UTC"`, or a visitor west of UTC sees the day before.
- Format a `datetime` with the time zone of your audience, like `timeZone: "Europe/Berlin"`. Without `timeZone`, the server's time zone is used, and that differs from the browser's.

## Date or datetime

| Type       | Stores                                         | Use it for                           |
| ---------- | ---------------------------------------------- | ------------------------------------ |
| `date`     | A day without time and time zone, `2026-10-17` | Birthdays, deadlines, all-day events |
| `datetime` | A moment in UTC, `2026-10-17T12:00:00.000Z`    | Start times, publish times           |

The admin shows a `datetime` in the editor's time zone and saves it in UTC. A `date` is the same day everywhere.

## Sort and compare

ISO strings sort in time order, so you can compare them as strings:

```ts
const today = new Date().toISOString().slice(0, 10);

const upcoming = (await cms.find("events"))
  .filter((event) => event.day >= today)
  .sort((a, b) => a.day.localeCompare(b.day));
```

A filter matches one exact value, like `where: { day: "2026-10-17" }`.
