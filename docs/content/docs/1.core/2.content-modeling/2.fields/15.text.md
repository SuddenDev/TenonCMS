---
title: Text
description: One line or several lines of text, stored as a string.
---

`text` is one line, like a title or a name. `textarea` is several lines, like a short summary.

:field-preview{name="text"}

:field-preview{name="textarea"}

## Example

```ts [cms/collections/posts.ts]
export const posts = defineCollection({
  fields: {
    title: { type: "text", required: true, maxLength: 80 },
    summary: { type: "textarea", rows: 3, placeholder: "One or two sentences" },
  },
});
```

A read returns a string:

```ts
const post = await cms.findOne("posts", { where: { slug } });
post?.title; // string
post?.summary; // string | null | undefined
```

### Render it

::code-group{sync="framework"}

```astro [Astro]
<h1>{post.title}</h1>
<p class="whitespace-pre-line">{post.summary}</p>
```

```vue [Nuxt]
<template>
  <h1>{{ post.title }}</h1>
  <p class="whitespace-pre-line">{{ post.summary }}</p>
</template>
```

```tsx [TanStack Start]
<>
  <h1>{post.title}</h1>
  <p className="whitespace-pre-line">{post.summary}</p>
</>
```

::

- All three escape the text, so a value cannot inject HTML.
- A `textarea` keeps its line breaks. `white-space: pre-line` shows them.

### Prefix and suffix

`prefix` and `suffix` show fixed text around the input. They are not stored:

```ts
domain: { type: "text", prefix: "https://", suffix: ".com" },
```

:field-preview{name="text-affixes"}

### Input mask

`mask` formats what the editor types. `#` is a digit, `@` a letter and `*` either:

```ts
cardNumber: { type: "text", mask: "#### #### #### ####" },
```

The admin shows `4242 4242 4242 4242`, but stores only the typed characters: `4242424242424242`.

### Pattern

`pattern` is a regular expression that MUST match the whole value:

```ts
zip: { type: "text", pattern: "\\d{5}" },
```

It is a string, not a `RegExp`, because the admin checks it too. It works like the HTML `pattern` attribute.

## Options

::field-group
:::field{name="type" type='"text" | "textarea"' required}
`text` is one line. `textarea` is several lines.
:::

:::field{name="placeholder" type="string"}
Shown in the empty input.
:::

:::field{name="minLength" type="number"}
The fewest characters. An empty optional value is not checked.
:::

:::field{name="maxLength" type="number"}
The most characters.
:::

:::field{name="pattern" type="string"}
A regular expression for the whole value. In a `textarea`, only the server checks it.
:::

:::field{name="prefix" type="string | { en, de, … }" :badges='[{"label":"text only","color":"callout"},{"label":"Admin only","color":"note"}]'}
Fixed text in front of the input, like `https://`. Not stored.
:::

:::field{name="suffix" type="string | { en, de, … }" :badges='[{"label":"text only","color":"callout"},{"label":"Admin only","color":"note"}]'}
Fixed text after the input, like `.com`. Not stored.
:::

:::field{name="mask" type="string" :badges='[{"label":"text only","color":"callout"},{"label":"Admin only","color":"note"}]'}
An input mask, like `"#### #### #### ####"`. `minLength`, `maxLength` and `pattern` check the stored value, so only the server checks them. See [Maska](https://beholdr.github.io/maska/) for the syntax.
:::

:::field{name="rows" type="number" :badges='[{"label":"textarea only","color":"callout"},{"label":"Admin only","color":"note"}]'}
The height of the empty input in lines. It grows with the content. Default `8`.
:::
::
