:field-preview{name="number"}

## Example

```ts [cms/collections/products.ts]
export const products = defineCollection({
  fields: {
    price: { type: "number", required: true, min: 0, step: 0.01 },
    rating: { type: "number", min: 1, max: 5, appearance: "stepper" },
    discount: { type: "number", min: 0, max: 100, step: 5, appearance: "slider" },
  },
});
```

A read returns a number:

```ts
product.price; // number
product.rating; // number | null | undefined
```

## Appearance

`appearance` picks the input in the admin. The stored value is the same.

| Appearance          | Input                                    |
| ------------------- | ---------------------------------------- |
| `"input"` (default) | A text box with up and down arrows       |
| `"plain"`           | A text box without buttons               |
| `"stepper"`         | Minus and plus buttons beside the number |
| `"slider"`          | A slider. Needs `min` and `max`          |

## Options

::field-group
:::field{name="type" type='"number"' required}
:::

:::field{name="min" type="number"}
The smallest value.
:::

:::field{name="max" type="number"}
The largest value.
:::

:::field{name="step" type="number"}
The value MUST be `min` (or `0`) plus a whole number of steps, like the HTML `step` attribute. `step: 0.01` allows two decimals.
:::

:::field{name="placeholder" type="string"}
Shown in the empty input.
:::

:::field{name="appearance" type='"input" | "plain" | "stepper" | "slider"' :badges='[{"label":"Admin only","color":"note"}]'}
The input in the admin. Default `"input"`.
:::
