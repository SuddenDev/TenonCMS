---
title: Boolean
description: A yes or no value, shown as a checkbox or a switch.
---

:field-preview{name="boolean"}

## Example

```ts [cms/collections/posts.ts]
export const posts = defineCollection({
  fields: {
    featured: { type: "boolean", label: "Show on the home page" },
    comments: { type: "boolean", appearance: "switch", default: true },
  },
});
```

A read returns `true` or `false`. An optional boolean can also be `null` or missing, so treat those as `false`:

```ts
const featured = await cms.find("posts", { where: { featured: true } });
```

### Render it

::code-group{sync="framework"}

```astro [Astro]
<article class:list={["post", { featured: post.featured }]}>
  {post.featured && <span class="badge">Featured</span>}
  <h2>{post.title}</h2>
</article>
```

```vue [Nuxt]
<template>
  <article class="post" :class="{ featured: post.featured }">
    <span v-if="post.featured" class="badge">Featured</span>
    <h2>{{ post.title }}</h2>
  </article>
</template>
```

```tsx [TanStack Start]
<article className={post.featured ? "post featured" : "post"}>
  {post.featured && <span className="badge">Featured</span>}
  <h2>{post.title}</h2>
</article>
```

::

A boolean is often the switch for a [condition](/docs/core/content-modeling/fields#conditions):

```ts
forSale: { type: "boolean" },
price: { type: "number", condition: { forSale: true } },
```
