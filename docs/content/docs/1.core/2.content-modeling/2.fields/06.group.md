---
title: Group
description: Fields nested under one key, shown as one section in the admin.
---

:field-preview{name="group"}

## Example

```ts [cms/collections/venues.ts]
export const venues = defineCollection({
  fields: {
    name: { type: "text", required: true },
    address: {
      type: "group",
      fields: {
        street: { type: "text" },
        zip: { type: "text", width: "1/3" },
        city: { type: "text", required: true, width: "2/3" },
      },
    },
  },
});
```

A read returns an object:

```ts
venue.address; // { street, zip, city } | null | undefined
venue.address?.city;
```

### Render it

::code-group{sync="framework"}

```astro [Astro]
{venue.address && (
  <address>
    {venue.address.street}<br />
    {venue.address.zip} {venue.address.city}
  </address>
)}
```

```vue [Nuxt]
<template>
  <address v-if="venue.address">
    {{ venue.address.street }}<br />
    {{ venue.address.zip }} {{ venue.address.city }}
  </address>
</template>
```

```tsx [TanStack Start]
{
  venue.address && (
    <address>
      {venue.address.street}
      <br />
      {venue.address.zip} {venue.address.city}
    </address>
  );
}
```

::

- An optional group can be missing, so read it with `?.`.
- A `required` field inside applies only when the group is there. Make the group `required` to demand it.
- Groups can hold groups, lists and every other field type.

## Tabs and boxes inside

A group can have its own `tabs` and `fieldsets`, like a collection. `appearance: "plain"` drops the box and heading, which fits a group that already sits in its own tab:

```ts
fields: {
  seo: {
    type: "group",
    tab: "seo",
    appearance: "plain",
    fields: {
      title: { type: "text" },
      description: { type: "textarea", rows: 3 },
    },
  },
}
```

## Limits

- Filters accept only top-level fields, not fields inside a group.
- `unique` does not work inside a group.
- `private` and `access` on a group apply to the whole group.
- In a localized collection, a group is localized as a whole. Its fields MUST NOT set `localized`.
