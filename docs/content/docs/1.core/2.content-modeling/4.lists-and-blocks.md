## Lists

- `array`: items that all have the same fields.

## Blocks

- `blocks`: items of different types, told apart by `blockType`.

## Shared and nested blocks

- Blocks defined once in `defineCms({ blocks })`. A block that contains itself.

## Read and render

- The types narrow by `blockType`. Link to [Components](/docs/core/building-your-site/components).
