## The field

- `richtext` stores a structured document, not HTML.
- `allowed` picks the features. `classes` gives editors CSS classes to apply.

## Links and images

- Links to documents follow path changes. Images come from the media library.

## Render on the site

- The `Richtext` component. An own component for a node.
- UI: `code-group` synced by framework.
