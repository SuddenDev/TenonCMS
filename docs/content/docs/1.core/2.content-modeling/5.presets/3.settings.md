title: Settings
description: Extend or remove the built-in general and seo globals.
---

The `settings()` preset gives every Tenon site two globals, `general` and `seo`. The admin lists them on its [Settings page](#the-settings-page).

| Global    | Fields                                                  |
| --------- | ------------------------------------------------------- |
| `general` | `title`, `tagline`, `favicon`                           |
| `seo`     | `title` and `description` templates, `image`, `noindex` |

To extend them, spread what `settings()` returns.

## Example

This example adds a phone number to `general` and removes `seo`:

```ts [tenon.config.ts]
import { defineCms } from "tenoncms";
import { settings } from "tenoncms/presets";

const { general } = settings();

export default defineCms({
  // ...
  settings: {
    general: { ...general, fields: { ...general.fields, phone: { type: "text" } } },
    seo: false,
  },
});
```

The `settings` option follows two rules:

- A key you leave out keeps its default.
- `false` removes a global. `settings: false` removes all of them, also the `translations` global of a localized site.

Read a settings global like any other global:

```ts
const general = await cms.getGlobal("general");
general.phone;
```


```tsx [TanStack Start]
import { createServerFn } from "@tanstack/react-start";
import cms from "../../tenon.config";

// Call it in a route's loader and pass the result to <Footer>.
export const getGeneral = createServerFn().handler(() => cms.getGlobal("general"));

export function Footer({ general }: { general: Awaited<ReturnType<typeof getGeneral>> }) {
  return (

      <strong>{general.title}</strong>

    </footer>
  );
}
```

The head tags of your site read both globals. To learn how, see [Site settings in Pages and SEO](/docs/core/building-your-site/pages-and-seo#site-settings).

## The Settings page

The Settings page lists every global or admin page whose `nav` has `display: "settings"`. The `settings()` globals use it, and so does the [menu](/docs/core/content-modeling/presets/menu) global. Give a global of your own the same `display` and it appears there too, not in the sidebar:

```ts [cms/globals/analytics.ts]
export const analytics = defineGlobal({
  nav: { display: "settings", group: "Tracking", icon: "chart-line", order: 5 },
  fields: { plausibleDomain: { type: "text" } },
});
```

| `nav` option | Effect on the Settings page                                  |
| ------------ | ------------------------------------------------------------ |
| `display`    | `"settings"` lists the entry here instead of in the sidebar. |
| `group`      | The section the entry sits in. Default `Site`.               |
| `icon`       | A [Lucide](https://lucide.dev/icons) icon name.              |
| `order`      | The position, lowest first. `general` is 1, `seo` is 2.      |

See [`nav`](/docs/core/content-modeling/collections-and-globals) for all `display` values.
