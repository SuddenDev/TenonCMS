## Field types

- All types by what they store. Link to the [field type reference](/docs/core/reference/field-types).
- UI: table.

## Common options

- `label`, `description`, `required`, `default`, `hidden`, `readOnly`, `private`.

## Types that need a word

- `slug`, `date` and `datetime`, `select`, `group`, `link`, `size`: one short example each.

## Validation

- Built-in checks, `validate` with a function or a Standard Schema, `unique`.
- Which rule runs in the admin and which on the server.

## Conditions

- `condition` shows a field only when other values match.
