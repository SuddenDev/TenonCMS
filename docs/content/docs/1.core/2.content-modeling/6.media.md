## The media library

- The default: files in `./.uploads`, images served as uploaded.
- The `media` options: `maxSize`, `accept`, `access`, `hooks`. `media: false` turns it off.
- Serverless hosts and Workers need a bucket. Link to [Media Storage](/docs/guide/databases-and-storage/media-storage).
- UI: `warning` callout.

## Image and file fields

- `image` and `file`, and what a populated one returns.

## Responsive images

- Sizes, presets, and the `Image` and `Picture` components.
- Resizing needs an [image provider](/docs/guide/databases-and-storage/image-providers).

## Upload from code

- `cms.media.upload()` for imports and seeds.
