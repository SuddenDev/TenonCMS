## The client

- `createClient()` from `tenoncms/client`: the same methods, typed.
- `baseUrl` and `apiKey` for other origins and services.

## What is public

- Reads of published content need no session. Writes need a session or an API key.

## Write from the site

- A comment form: one access rule and one client call.
