## The local API

- Server code calls the instance directly, without HTTP.
- How each framework gets the instance.
- UI: `code-group` synced by framework.

## Find documents

- `find`, `findOne`, `findById`, `getGlobal`, with `where` and `limit`.

## Pick fields and relations

- `select` and `populate`. The result type follows.

## Drafts

- Reads return published content. `withSession(request)` shows drafts to a signed-in editor in the preview.

## Result types

- `DocumentOf`, `GlobalOf` and `BlockOf` for component props.
