title: Email
description: Send account emails and own messages.
---

## What email is for

- Password resets, invites, sign-in links. Email is optional.

## Set up SMTP

- Nodemailer, `email.adapter` and `from`.

## Send from your code

- `cms.email.send()`.

## Templates and other providers

- Change the built-in emails. An adapter is one `send` function.
