## Blocks

`Blocks` renders a [blocks field](/docs/core/content-modeling/fields/blocks) with one component per block type:

::code-group{sync="framework"}

```astro [Astro]
---
import { Blocks } from "tenoncms/astro/components";
import Hero from "../blocks/Hero.astro";
import Text from "../blocks/Text.astro";
---

<Blocks blocks={page.content} components={{ hero: Hero, text: Text }} />
```

```vue [Nuxt]
<script setup lang="ts">
import Hero from "~/components/blocks/Hero.vue";
import Text from "~/components/blocks/Text.vue";
</script>

<template>
  <TenonBlocks :blocks="page.content" :components="{ hero: Hero, text: Text }" />
</template>
```

```tsx [TanStack Start]
import { Blocks } from "tenoncms/react";
import { Hero } from "../blocks/Hero";
import { Text } from "../blocks/Text";

<Blocks blocks={page.content} components={{ hero: Hero, text: Text }} />;
```

::

Each component gets the item as its `block` prop.

## Richtext

`Richtext` turns a [rich text field](/docs/core/content-modeling/fields/rich-text) into HTML. It renders on the server, adds no styles and loads no editor:

::code-group{sync="framework"}

```astro [Astro]
---
import { Richtext } from "tenoncms/astro/components";
---

<Richtext content={post.body} class="prose" />
```

```vue [Nuxt]
<template>
  <TenonRichtext :content="post.body" class="prose" as="article" />
</template>
```

```tsx [TanStack Start]
import { Richtext } from "tenoncms/react";

<Richtext content={post.body} className="prose" />;
```

::

- `content` can be `null` or `undefined`.
- Read the field with `populate`, the default, so links and images have their current URLs. The component fetches nothing.
- `as` sets the outer element. The default is `div`.
- Outside these frameworks, `renderRichtext(content)` from `tenoncms/richtext` returns the same HTML as a string.

### Your own nodes

A feature you add yourself, like a notice box, needs a renderer on the site too. Pass its Tiptap extension in `extensions`, keyed by the feature name. The extension's `renderHTML` decides the markup:

```astro
<Richtext content={post.body} extensions={{ notice: [Notice] }} />
```

The extension MUST work without a browser DOM. To add a feature to the editor, see [Plugins](/docs/core/customization/plugins).
