---
title: Menus
description: Navigation menus that editors arrange as a tree.
---

## Set it up

- `menuPreset({ name, depth })` adds a menu global.

## Render it

- `menuItems()` turns a read into entries with `label`, `href` and `children`.
- UI: `code-group` synced by framework.

## Customize it

- Extra fields, a second menu, languages.
