---
title: Live Preview
description: Editors see changes on the real page while they type.
---

One of the most requested (and helpful) features that clients often request: A live preview where editors see the real site next to the form. In Tenons case, every change shows up on the page while they type, before they save in real-time.

![Tenon CMS](/images/tenon-live_preview_example.jpg)

## Set it up

::steps{level="3"}

### Say where a document lives

Set `permalink` on each collection that has its own pages. The admin opens that URL in the frame:

```ts [cms/collections/posts.ts]
export const posts = defineCollection({
  permalink: "/posts/{slug}",
  fields: {
    title: { type: "text", required: true },
    slug: { type: "slug", from: "title" },
  },
});
```

The pages preset sets it for you. See [Permalinks](/docs/core/building-your-site/pages-and-seo#permalinks) for placeholders and functions.

### Mark the elements

`edit()` from `tenoncms/preview` names the field an element shows. Put it in `data-cms`:

::code-group{sync="framework"}

```astro [Astro]
---
import { edit } from "tenoncms/preview";
---

<h1 data-cms={edit("posts", post.id, "title")}>{post.title}</h1>
<p data-cms={edit("posts", post.id, "author.name")}>{post.author.name}</p>
```

```vue [Nuxt]
<script setup lang="ts">
import { edit } from "tenoncms/preview";
</script>

<template>
  <h1 :data-cms="edit('posts', post.id, 'title')">{{ post.title }}</h1>
  <p :data-cms="edit('posts', post.id, 'author.name')">{{ post.author.name }}</p>
</template>
```

```tsx [TanStack Start]
import { edit } from "tenoncms/preview";

<h1 data-cms={edit("posts", post.id, "title")}>{post.title}</h1>
<p data-cms={edit("posts", post.id, "author.name")}>{post.author.name}</p>
```

::

A marked element gets the new text on every keystroke. In the visual editor, a click on it opens its field.

- For a global, pass `null` as the id: `edit("general", null, "title")`.
- For a field inside a list, use the position: `edit("pages", page.id, "content.2.title")`. For blocks, the [Blocks component](/docs/core/building-your-site/components#click-to-edit-inside-blocks) does this for you.
- For an image, add `data-cms-attr="src,srcset,alt"`, so the attributes change instead of the text. The [Image component](/docs/core/building-your-site/components#image) does this when the element has `data-cms`.

::

## Per framework

Marked elements update in every framework. What else follows while the editor types depends on how the framework renders:

::tabs{sync="framework"}

:::tabs-item{label="Astro"}

The integration starts the preview on every page and reads drafts for you. There is nothing to add.

Astro pages render on the server. While an editor types, only marked elements change. After each save, the page loads again in the background and swaps in the new HTML, so lists and conditions catch up.

To leave the preview out, pass `preview: false` to the integration:

```ts [astro.config.ts]
export default defineConfig({
  integrations: [tenonCms({ preview: false })],
});
```

:::

:::tabs-item{label="Nuxt"}

The module starts the preview on every page and reads drafts for you. There is nothing to add.

`useTenon()` merges the unsaved changes into the data of `find`, `findOne`, `findById` and `getGlobal`. The whole page follows while the editor types, lists and conditions included.

Every document a page reads also shows under **On this page** in the visual editor. Editors can open it from there, even without `edit()`. Add `edit()` for outlines and clicks.

:::

:::tabs-item{label="TanStack Start"}

TanStack Start needs three additions:

1. Read with `cms.withSession(getRequest())` in the server function, so the page shows drafts. See [Drafts](/docs/core/working-with-content/reading#drafts).
2. Call `preview()` once in the root route. For visitors without a session, it does nothing.
3. Pass the loader data through `useDraft()`. It merges the unsaved changes, so the whole page follows while the editor types.

```tsx [src/routes/__root.tsx]
import { useEffect } from "react";
import { preview } from "tenoncms/preview";

function Root() {
  useEffect(() => preview(), []);
  // ...
}
```

```tsx [src/routes/posts/$slug.tsx]
import { useDraft } from "tenoncms/preview/react";

function Post() {
  const post = useDraft("posts", Route.useLoaderData());
  return <h1>{post.title}</h1>;
}
```

For a global, pass its name: `useDraft("footer", footer)`. In Vue outside Nuxt, `useDraft()` from `tenoncms/preview/vue` returns a ref.

:::

::

## Prerendered pages and preview routes

A prerendered page is built once, at deploy time. It cannot show drafts, so the preview would show the last deploy.

Give the collection a second route that renders on each request, and point `preview` at it. `permalink` stays the public URL:

```ts [cms/collections/posts.ts]
export const posts = defineCollection({
  permalink: "/posts/{slug}",
  preview: "/preview/posts/{slug}",
  fields: {
    // ...
  },
});
```

```astro [src/pages/preview/posts/[slug].astro]
---
import Post from "../../../components/Post.astro";

export const prerender = false;

const post = await Astro.locals.tenon.findOne("posts", {
  where: { slug: Astro.params.slug },
});
if (!post) return new Response(null, { status: 404 });
---

<Post post={post} />
```

- Both routes render the same component, so the preview matches the public page.
- To show published changes on the public page, rebuild the site. A [webhook](/docs/core/operations/webhooks) can start the build when an editor publishes.

## Keep content out of edit mode

Some content is not for editors to change on the page, like comments that visitors write. `visualEditing: false` keeps it out of the visual editor:

```ts
export const comments = defineCollection({
  visualEditing: false,
  fields: { body: { type: "text" } },
});
```

Its elements get no outline, and **On this page** leaves the collection out. A click on one opens the marked element around it, if there is one.

## Check for the live preview

`isLivePreview()` from `tenoncms/preview` tells whether the page runs inside the admin's preview, for example to skip an intro animation:

```ts
import { isLivePreview } from "tenoncms/preview";

if (!isLivePreview()) playIntro();
```

- On the server, pass the request's headers: `isLivePreview(request.headers)`. They only show the admin's frame, so a preview tab is `false` until the page runs in the browser.
- In Nuxt, `useLivePreview()` returns the same answer as a ref.
