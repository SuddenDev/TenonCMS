title: Access Control
description: Roles, rules and API keys.
---

## Roles

- `admin`, `editor` and own roles. How users are invited.

## Rules

- `access` on collections, globals, media and fields: `true`, `false`, roles or a function.
- The default: everyone reads published content, signed-in users do the rest.

## Limit to some documents

- A rule returns a `where`: an author changes only their own posts.

## Server code

- The server instance skips the rules. `withSession(request)` applies them.

## API keys

- For scripts and other services. Permissions per target.
- A key reads published content only and stays on the server.
