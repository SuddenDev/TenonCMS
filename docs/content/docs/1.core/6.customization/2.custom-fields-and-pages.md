title: Custom Fields and Pages
description: Add own inputs, pages and buttons to the admin, in any UI library.
---

## Server and browser

- The config runs on the server, admin code in the browser. `.client.ts` modules and `clientRef()` connect them.

## The `mount` function

- Every slot is one function: it gets an element and a context, and returns a cleanup.
- UI: `code-group` with plain DOM, Vue and React.

## Custom fields

- An input for `custom:<name>`.

## Custom pages

- `pages` adds routes to the admin. `load` fetches data on the server.

## Actions

- One-click buttons that run server code: `label`, `run`, `confirm`, `access`.
