## Branding

- Name, logo, icon and favicon.

## Navigation

- `nav` on collections, globals, pages and media: `display`, `group`, `icon`, `order`.
- UI: `field-group`.

## Languages

- The admin speaks English and German. Labels take one string per language.

## Admin bar

- The bar signed-in editors see on the site: logo and site name, Edit, Drafts/Published, close. Visitors never load it.
- `admin.adminBar`: `position` (eight positions, default `bottom-center`), `items` (link, dropdown, button, own control), `load` per page, `false` removes an item, `adminBar: false` turns the bar off.
- Built-in items: `dashboard` (10), `edit` (20), `perspective` (30). Buttons and own controls: link to Plugins.

## Path

- `admin.path`, and `admin: false` for headless.
